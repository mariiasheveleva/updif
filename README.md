## 1. Введение

В современном мире автоматизация помогает экономить время на рутинных задачах. Интеграционные платформы позволяют соединять разные сервисы без написания сложного кода. Пользователь просто собирает схему из готовых блоков, как конструктор.

**Цель работы:** Сравнить три интеграционные платформы (две российские и одну зарубежную) и создать простейшую автоматизацию на одной из них без использования Docker и локальных установок.

**Задачи:**
1. Рассмотреть платформы Make.com, Hub Studio и Albato.
2. Сравнить их по основным критериям.
3. Сделать простую автоматизацию обработки текстовых данных в облачном сервисе.

---

## 2. Что такое интеграционные платформы

**Интеграционная платформа** — это сервис, который позволяет соединять разные приложения и автоматически обмениваться данными между ними.

**Low-code платформа** — это среда, где можно создавать программы с помощью визуальных блоков, почти не используя код.

**Пример использования:** Вы хотите автоматически обрабатывать текстовые данные, преобразовывать их и сохранять результат. Интеграционная платформа делает это за несколько минут.

---

## 3. Критерии сравнения

Для сравнения платформ будем использовать следующие критерии:

1. **Происхождение** — российская или зарубежная.
2. **Бесплатная версия** — есть ли возможность использовать без оплаты.
3. **Простота освоения** — насколько легко новичку разобраться.
4. **Облачный доступ** — нужна ли установка или работает в браузере.
5. **Возможность обработки данных** — есть ли блоки для трансформации данных.

---

## 4. Платформа 1: Make.com (бывший Integromat)

**Make.com** — зарубежная облачная платформа для автоматизации, одна из самых популярных в мире.

**Особенности:**
- Работает полностью в браузере, ничего устанавливать не нужно.
- Бесплатный тариф на 1000 операций в месяц.
- Более 1000 готовых приложений для интеграции.
- Визуальный редактор с перетаскиванием блоков.

**Плюсы:**
- Не требует установки — работает в любой ОС.
- Понятный русскоязычный интерфейс.
- Бесплатно для начала и обучения.
- Огромное количество обучающих материалов.

**Минусы:**
- Зарубежная платформа (данные хранятся не в РФ).
- На бесплатном тарифе есть ограничения.

---

## 5. Платформа 2: Hub Studio (российская)

**Hub Studio** — российская low-code платформа от компании HubEx.

**Особенности:**
- Входит в реестр отечественного ПО.
- Ориентирована на бизнес и госсектор.
- Данные хранятся в России.

**Плюсы:**
- Полностью на русском языке.
- Безопасно для персональных данных (152-ФЗ).
- Подходит для крупных компаний.

**Минусы:**
- Платная (нет бесплатного тарифа для физических лиц).
- Сложная для новичка.
- Требует регистрации через юрлицо.

---

## 6. Платформа 3: Albato (российская)

**Albato** — российская облачная платформа для автоматизации процессов.

**Особенности:**
- Полностью российская разработка.
- Есть бесплатный тариф на 100 операций в месяц.
- Работает в браузере, установка не требуется.
- Поддержка российских сервисов (Битрикс24, amoCRM, МойСклад).

**Плюсы:**
- Бесплатный тариф для обучения.
- Понятный интерфейс на русском языке.
- Данные хранятся в России.
- Простая регистрация через email.

**Минусы:**
- Меньше интеграций, чем у Make.com.
- На бесплатном тарифе мало операций.

## 8. Выбор платформы

Для практической части я выбрал **Make.com** по трём причинам:

1. **Не требует установки** — всё работает в браузере.
2. **Бесплатно** — 1000 операций в месяц достаточно для учебных целей.
3. **Просто** — визуальный редактор с перетаскиванием блоков.

**Что будем делать:**
Создадим автоматизацию из двух шагов:
1. Ввод текста вручную (триггер "Watch events").
2. Преобразование текста в верхний регистр (функция upperCase).

## 9. Практическая часть: простейшая автоматизация

### Цель:
Настроить автоматическую обработку текста — преобразование любой введённой строки в заглавные буквы с помощью Make.com.

### Что нужно:
1. Зарегистрироваться на Make.com (бесплатно).
2. Браузер (Chrome, Firefox, Edge).
3. 10 минут свободного времени.

### Как это работает (простыми словами):
- Вы заходите в Make.com и создаёте новый сценарий.
- Добавляете блок "Tools" (инструменты).
- Настраиваете функцию преобразования текста.
- Запускаете и смотрите результат.

## 10. Пошаговая инструкция

### Шаг 1. Регистрация на Make.com

1. Откройте браузер и перейдите на сайт: **https://www.make.com**
2. Нажмите кнопку **"Sign up"** (Зарегистрироваться).
3. Выберите способ регистрации: через email, Google или Facebook.
4. Подтвердите email (придёт письмо).
5. Войдите в аккаунт.

### Скриншот 1. Главный экран Make.com после регистрации

![Главный экран Make.com](img/1.png)

*На скриншоте видна главная страница Make.com с кнопкой "Create a new scenario" для создания нового сценария.*

---

### Шаг 2. Создание нового сценария

1. Нажмите кнопку **"Create a new scenario"** (Создать новый сценарий).
2. Откроется визуальный редактор — пустое поле для автоматизации.

### Скриншот 2. Пустой редактор сценариев

![Пустой редактор Make.com](img/screen_2_blank.png)

*На скриншоте показан пустой редактор Make.com с надписью "Click to add a module" (нажмите, чтобы добавить модуль).*

---

### Шаг 3. Добавляем модуль обработки данных

1. Нажмите на пустое место (или на значок "?" в центре).
2. В поиске введите **"Tools"**.
3. Выберите модуль **Tools**.
4. Выберите действие **"text functions"** (текстовые функции).

### Скриншот 3. Выбор модуля Tools

![Выбор модуля Tools](img/screen_3_tools.png)

*На скриншоте показано окно выбора модуля, где выделен Tools и действие text functions.*

---

### Шаг 4. Настройка преобразования текста

В открывшемся окне настройки:

1. В поле **"Function"** выберите **"upperCase"** (преобразование в верхний регистр).
2. В поле **"Text"** напишите любой текст, например: `привет мир`
3. Нажмите **"OK"**.

### Скриншот 4. Настройка функции upperCase

![Настройка функции upperCase](img/screen_4_uppercase.png)

*На скриншоте видно окно настроек модуля Tools: в поле Function выбрано "upperCase", в поле Text введено "привет мир".*

---

### Шаг 5. Запуск и проверка

1. Нажмите кнопку **"Run once"** (Запустить один раз) внизу экрана.
2. Модуль выполнится и покажет результат.
3. Результат будет отображаться внизу под модулем.

### Скриншот 5. Результат выполнения

![Результат выполнения Make.com](img/screen_5_result.png)

*На скриншоте показан выполненный модуль Tools. Внизу виден результат выполнения: текст "ПРИВЕТ МИР" в верхнем регистре.*

---

### Шаг 6. Сохранение сценария

1. Нажмите кнопку **"Save"** (Сохранить) в правом верхнем углу.
2. Дайте имя сценарию, например: `Преобразование текста в верхний регистр`
3. Нажмите "Save".
